Phishing URL Detection & Risk Analysis Tool

A rule-based web application that analyzes URLs in real time to detect phishing attempts, assign risk scores, and help users stay safe online.

About the Project
What does this tool do?

This tool lets authenticated users paste any URL and instantly receive a risk score (0–100) along with a list of detected phishing signals. The analysis engine inspects the URL for suspicious patterns such as misleading domain names, excessive subdomains, encoded characters, brand impersonation, and known phishing keywords — all without querying external databases, making results instantaneous.

Features
What's included
🔍

URL Analysis

Deep inspection of every URL component — scheme, domain, path, query, and fragment.

📊

Risk Scoring

A weighted 0–100 risk score classifies URLs as Safe, Suspicious, or Dangerous.

🔐

Login System

Session-based authentication keeps the dashboard protected from unauthorized access.

📜

Scan History

The last 10 scanned URLs are stored per session so you can review past results.

How It Works
Rule-based detection pipeline
1

Input & Expand

The URL is normalised and any short-links are expanded to reveal the true destination.

2

Pattern Analysis

Dozens of heuristics check for IP addresses in hostnames, lookalike characters, excessive dashes, long paths, and more.

3

Keyword & Brand Check

The URL is scanned for phishing keywords and brand names frequently targeted by attackers.

4

Score & Classify

Weighted signals produce a final 0–100 risk score and a human-readable classification.
